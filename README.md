# Language Theatre & Games

GitHub Pages ready static website.

## Files
- `index.html` — main bilingual / multilingual menu
- `romeo-juliet.html` — Romeo and Juliet role assignment
- `liang-shanbo.html` — Liang Shanbo and Zhu Yingtai role assignment
- `undercover.html` — Who Is the Undercover game

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload all four HTML files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. Open the GitHub Pages URL shown by GitHub.

The homepage is `index.html`.
